# Assets de LINHA MORTA

Arte gerada e integrada:

- `cover_linha.png` — capa do jogo (864x1152, gerada por IA): painel de central
  telefônica com cabos sob luz de lâmpada verde.
- `panel_splash.png` — tela de abertura da central (1344x768, gerada por IA).

Os PNGs em alta ficam no ZIP de entrega (o canal da API de escrita transporta
apenas texto). No repositório, a versão integrada está comprimida em
`src/embedded.js` (data URI). A arte do painel de jacks é SVG procedural em
`src/board.js`.
